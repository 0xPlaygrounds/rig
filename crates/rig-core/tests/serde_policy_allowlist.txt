# Allowlist for the serde policy wall (see driver_adoption.rs,
# `provider_streaming_modules_never_raw_parse_the_wire`).
#
# Format: `path suffix | line snippet | one-line justification`.
# Every entry must justify why the raw parse is NOT wire-frame triage:
# frame decoding belongs to the wire.rs classifiers and the adapter driver.
# Stale entries (matching no shipped line) fail the guard — delete them
# alongside the code they covered.

# --- shared Chat Completions-compatible helper: in-band error triage -------
providers/internal/openai_chat_completions_compatible.rs | serde_json::from_str::<serde_json::Value>(data).ok()?; | provider_response_from_compatible_sse_data deliberately runs pre-classification: compatible gateways send in-band error envelopes as data frames ("Treat the chunk as an error only when `error` is present AND carries a payload ... canonical OpenAI-compatible error event"), so it peeks for a populated `error` key (with no `choices`) to surface a CompletionError; unparseable or non-error chunks fall through to the classifier untouched.

# --- shared Chat Completions-compatible helper: blocking choice decode -----
providers/internal/openai_chat_completions_compatible.rs | && serde_json::from_value::<T>(repaired).is_ok() | Validates a repaired copy of an already-deserialized blocking response choice before dropping incomplete tool arguments; it cannot classify or skip a streaming frame, and failure keeps the original choice on the loud decode path.
providers/internal/openai_chat_completions_compatible.rs | serde_json::from_value(choice).map_err(serde::de::Error::custom) | Performs the final typed decode of an already-deserialized blocking response choice after output-length tool-call policy; every failure is returned as a serde error, never triaged or skipped as a stream frame.

# --- openai Responses websocket: websocket-only envelope pre-dispatch ------
# `error` and `response.done` are transport envelopes outside the modeled
# Responses event set; parse_server_event dispatches exactly those two and
# routes every other frame through classify_responses_frame + triage_frame.
providers/openai/responses_api/websocket.rs | serde_json::from_str::<EventType>(payload) | Reads only the `type` tag to dispatch the two websocket-only envelopes; a corrupt payload errors, never skips.
providers/openai/responses_api/websocket.rs | "error" => serde_json::from_str(payload) | Decodes the websocket-only `error` envelope (outside the modeled Responses set); decode failure is a CompletionError.
providers/openai/responses_api/websocket.rs | "response.done" => serde_json::from_str(payload) | Decodes the websocket-only `response.done` envelope (outside the modeled Responses set); decode failure is a CompletionError.
providers/openai/responses_api/websocket.rs | serde_json::from_value(status) | Reads the optional `status` field of an already-decoded `response.done` payload for turn-state bookkeeping; absence/mismatch falls into an explicit handled arm.
providers/openai/responses_api/websocket.rs | serde_json::from_value(self.response.clone()) | Attempts the full CompletionResponse view of an already-decoded `response.done` payload; the None case is handled with an explicit provider error, not a skip.

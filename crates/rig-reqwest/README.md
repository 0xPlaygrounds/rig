# rig-reqwest

The bundled [`reqwest`](https://docs.rs/reqwest) HTTP transport for [Rig](https://crates.io/crates/rig). `ReqwestClient` and `ReqwestMiddlewareClient` wrap host-built clients and implement rig-http's transport contract. `ReqwestClient::default()` and `client::shared()` use the same process-wide connection pool. Client-build failures never panic: each send reports the saved error with its source chain. `inner()` and `into_inner()` are fallible; no `AsRef` implementation hides a failed default. Provider-specific constructors belong to rig-core behind its `reqwest` feature.

Environment-derived proxy and certificate settings are read once when the default is first constructed. Later environment changes do not replace that client or retry a failed build. Construct an explicit client to use different settings.

This crate depends on `rig-http`, never on `rig-core`. Transport execution and runtime ownership stay here; rig-core's default feature graph contains neither. On native targets, the shared default always uses a lazily started process-wide reactor so its pooled connections cannot depend on a short-lived caller's runtime. Explicit clients capture the caller's Tokio context, using that same fallback reactor outside Tokio (Bevy task pools, smol, `futures::executor`). Each poll enters the selected context; no detached per-request or stream-forwarding worker owns the operation. Dropping a request, response body or stream releases its local operation without waiting for another upstream chunk. It cannot undo a remotely accepted request.

For explicit clients, a host runtime must enable I/O and timers and remain driven. Context detection does not prove this; a runtime without its reactor can panic during I/O. A handle alone does not keep a runtime alive. Stop admitting work, cancel/drain owned operations, release shared clients, then shut down the runtime. Supplied endpoint, proxy, redirect, TLS and timeout policy remains with the host-built client. WASM uses its native browser transport path, not the native Tokio fallback.
